## Corrections

- `ed3f346` forwards nested expression typechecker warnings instead of dropping them. ADT `example_5.vpr` previously omitted three source warnings for unconstrained type parameters. The source grounding rule is in [Silver Resolver.scala](https://github.com/viperproject/silver/blob/c4f54b84703a04434b03e97bfea87dbd09870fd2/src/main/scala/viper/silver/parser/Resolver.scala#L516-L538).
- `7f77976` sends annotation warnings and stdio/linked solver warnings as their source reporter event types while retaining the raw `take_warnings()` buffer and reporting failures. Silicon uses [AnnotationWarning](https://github.com/viperproject/silicon/blob/ff386aec4664231dc6f2cb56d8d35f1623088363/src/main/scala/supporters/AnnotationSupporter.scala#L52) and [InternalWarningMessage for stdio prover warnings](https://github.com/viperproject/silicon/blob/ff386aec4664231dc6f2cb56d8d35f1623088363/src/main/scala/decider/ProverStdIO.scala#L470-L477); [Z3 API warnings](https://github.com/viperproject/silicon/blob/ff386aec4664231dc6f2cb56d8d35f1623088363/src/main/scala/decider/Z3ProverAPI.scala#L267-L280) use the latter event as well. The reporter list and convenience buffer are separate observations and must not be added together.
- `ec3c969` uses the source quantified-heap split order consistently for summaries, consumption and field access, while keeping the forward `forperm` collection path. The old order could select stale snapshot cache keys and omit 0648 prover warnings. One v3 guarded quantified body and trigger matched the pinned source after whitespace and prover-name normalization; that observation does not establish whole-script equality. The source split operation is in [QuantifiedChunkSupport.scala](https://github.com/viperproject/silicon/blob/ff386aec4664231dc6f2cb56d8d35f1623088363/src/main/scala/rules/QuantifiedChunkSupport.scala#L405-L424).
- `1284c89` computes mask-frame declarations at the source phase boundary before merging recorders, then declares fresh unresolved symbols to workers before replaying dependent axioms. The earlier ordering omitted warnings; an intermediate candidate also let a worker receive an undeclared `$unresolved` symbol. Source phase ordering is in [FunctionData.scala](https://github.com/viperproject/silicon/blob/ff386aec4664231dc6f2cb56d8d35f1623088363/src/main/scala/supporters/functions/FunctionData.scala#L169-L175); [FunctionVerificationUnit.scala](https://github.com/viperproject/silicon/blob/ff386aec4664231dc6f2cb56d8d35f1623088363/src/main/scala/supporters/functions/FunctionVerificationUnit.scala#L323-L333) re-declares fresh variables to the solver sink.
- `afdf10c` matches the pinned linked Z3 retry cleaner. In [Z3ProverAPI.scala](https://github.com/viperproject/silicon/blob/ff386aec4664231dc6f2cb56d8d35f1623088363/src/main/scala/decider/Z3ProverAPI.scala#L267-L310), a total partial function collects a Boolean for every trigger root; [Silver's shallow collector](https://github.com/viperproject/silver/blob/c4f54b84703a04434b03e97bfea87dbd09870fd2/src/main/scala/viper/silver/ast/utility/Visitor.scala#L161-L179) retains `false` as an element. Consequently the actual source retry removes every nonempty trigger group and retains empty groups. Native now follows that behavior, including nested quantifiers and error propagation. The previous narrower cleanup retried malformed patterns unchanged and raised an exceptional error on `array_exhale.vpr`.
